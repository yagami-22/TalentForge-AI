# TalentForge AI Features

## Resume Intelligence

Upload and analyze text-based PDF resumes. TalentForge extracts resume text, validates quality, detects evidence, scores resume strength, and surfaces issues, quick wins, and red flags.

## ATS Optimization

Compare a resume against a target job description. The module identifies ATS keyword matches, missing keywords, weak bullets, formatting issues, and prioritized improvements.

## JD Match

Analyze role fit against a job description. JD Match highlights matched skills, missing skills, match score, evidence gaps, and recruiter-facing fit signals.

## Resume Rewriter

Generate tailored professional summaries, experience bullets, skills sections, ATS keywords, and improvement notes from a selected resume and job description. Users can export rewritten content as PDF.

## Resume Version History

Track resume versions created by analysis, rewrite, restore, and optimization workflows. Version History includes comparison metrics, skill and keyword changes, trend charts, and restore functionality.

## GitHub Profile Analyzer

Analyze public GitHub profiles and repositories using evidence-based scoring.

Signals include:

- Architecture
- Codebase quality
- Production readiness
- Deployment evidence
- Documentation
- Maintainability
- Real-world impact
- Modern stack usage
- Recruiter visibility

The analyzer recommends top recruiter projects, verified skills, proof gaps, and resume integration opportunities.

## AI Recruiter Mode

Evaluate one or more candidate resumes against a job description. Recruiter Mode produces evidence-based candidate rankings, hire recommendations, seniority mismatch handling, strengths, weaknesses, risks, and interview questions.

## Mock Interviews

Create company-style interview sessions across multiple modes:

- Technical Interview
- DSA Interview
- Frontend Interview
- Backend Interview
- System Design Interview
- Project Deep Dive
- Behavioral / HR
- Mixed Interview

Interview sessions include question cards, timers, answer input, hints, follow-ups, progress, and evaluation reports.

## Career Coach

Career Coach combines signals from resumes, ATS, JD matching, interviews, projects, skills, GitHub evidence, and version history to create a readiness score and weekly roadmap.

It includes:

- Career readiness categories
- Personalized roadmap
- Target company readiness
- Skill gap radar
- Learning recommendations
- Weekly progress
- Achievements and milestones

## Premium Dashboard

The dashboard gives users a unified command center for career readiness, quick actions, analytics, recent activity, module navigation, and cross-module recommendations.
